# Kasir Mini

Template kasir (POS) mobile-first sederhana. Tampilan satu kolom dengan tab Katalog, Keranjang, dan Struk. Cocok untuk kasir HP dengan layar kecil.

## Fitur
- Katalog produk grid responsif (2-3 kolom)
- Keranjang dengan kontrol_qty per produk
- Diskon persen
- Struk siap cetak (printer thermal)
